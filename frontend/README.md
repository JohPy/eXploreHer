# README
### Frontend Guide

1. In den richtigen Ordner navigieren: `cd frontend/`
2. Abhängigkeiten installieren: `yarn install`
3. Entwicklungsmodus starten: `yarn watch`
4. In einem neuen Terminal: `yarn start`

**Hinweis:**  
- Stelle sicher, dass Node.js und Yarn installiert sind.
- `yarn watch` überwacht Quellcodedateien und kompiliert bei Änderungen automatisch neu.
- `yarn start` startet den lokalen Entwicklungsserver.
