# README

## Projektüberblick
Dieses Projekt ist eine Lern-App für junge Frauen, die dabei unterstützt, mehr über weibliche Gesundheitsaspekte zu erfahren. Die Zielgruppe sind junge Frauen, die ihr Wissen spielerisch erweitern möchten. Zu den Hauptfunktionen gehören ein Drag-and-Drop-Bildschirm, auf dem Begriffe interaktiv einer Grafik zugeordnet werden können, sowie ein Wortzuordnungs-Quiz, das das Verständnis weiter vertieft. Die App legt Wert auf eine positive und bestärkende Nutzererfahrung.
### Value Proposition:
Wir helfen jungen Frauen das Selbstvertrauen in den eigenen Körper zu leveln, indem wir sie in einer spielerischen Anwendung zu Expertinnen ihres eigenen Körpers ausbilden.
